Label color ramps

Pills carry color; cards stay white. red / amber / blue are locked from spec + mockups. slate / teal / coral / purple / pink are derived to the same lightness/saturation logic (fg ≈ L45%, bg ≈ L95%). Each ramp = -fg (text/border) + -bg (pastel fill).
